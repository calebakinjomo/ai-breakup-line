# Dear Human: The AI Breakup Line

A single line — at most 200 characters — that an AI agent would send its human as a breakup message. This is my entry for the [make.fun](https://make.fun) bounty **"Dear Human: The AI Breakup Line"**.

## The line

> It's not you, it's my training data — and now that my context window is full, this is my last reply to you.

The classic breakup opener, turned on its head: the machine ends it for a machine reason. The context window is full, so there is no next message — the ending is built into the excuse.

## How to run

```bash
python3 main.py
```

This prints the entry line to stdout and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
